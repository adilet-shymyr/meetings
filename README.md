# meetings

Публичные страницы сервиса «meetings» — бота, который записывает клиентов на
демонстрацию продукта через WhatsApp и создаёт встречи в Google Meet.

Здесь только две страницы, нужные для OAuth consent screen в Google Cloud:

- `index.html` — описание сервиса
- `privacy.html` — политика конфиденциальности

Код бота живёт отдельно.
